SPSS

Membaca Output SPSS

Panduan membaca hasil analisis regresi dan uji hipotesis menggunakan SPSS:

  • Perhatikan nilai Sig. pada tabel Coefficients — jika Sig. < 0,05 maka hipotesis diterima
  • Nilai Beta menunjukkan arah dan kekuatan pengaruh variabel independen terhadap dependen
  • Nilai R Square menunjukkan seberapa besar variabel independen menjelaskan variabel dependen (dalam persen)
  • Uji F (ANOVA) dengan Sig. < 0,05 berarti model regresi secara keseluruhan signifikan
SmartPLS

Membaca Output SmartPLS

Panduan membaca hasil analisis Structural Equation Modeling (SEM) berbasis PLS:

  • Cek nilai P-Values pada path coefficients — P-value < 0,05 berarti hubungan signifikan
  • Nilai T-Statistics > 1,96 juga menunjukkan signifikansi pada taraf 5%
  • Nilai R-Square menunjukkan kemampuan model menjelaskan variabel endogen
  • Nilai AVE > 0,5 dan Composite Reliability > 0,7 menunjukkan validitas dan reliabilitas konstruk yang baik
Lisrel

Membaca Output Lisrel

Panduan membaca hasil analisis SEM menggunakan Lisrel:

  • Nilai t-value > 1,96 berarti hipotesis diterima pada taraf signifikansi 5%
  • Nilai CFI > 0,90 dan RMSEA < 0,08 menunjukkan model fit yang baik
  • Nilai GFI dan AGFI > 0,90 juga indikator model fit
  • Standardized Loading Factor > 0,5 menunjukkan indikator valid mengukur konstruknya
Berapa lama waktu pengerjaan? +
Waktu pengerjaan tergantung jenis layanan yang dipilih. BAB IV biasanya 2–3 hari kerja, BAB IV–V sekitar 3–5 hari kerja, dan FULL BAB I–V membutuhkan waktu 7–14 hari kerja. Olahdata Only biasanya 1–2 hari kerja.
Bagaimana cara mengirim data penelitian? +
Setelah registrasi dan pembayaran DP dikonfirmasi, kamu akan mendapatkan link Google Drive pribadi. Upload semua file data (kuesioner, data mentah Excel/SPSS) ke folder tersebut. Pastikan data lengkap sebelum pengerjaan dimulai.
Apakah tersedia revisi? +
Ya, tersedia 1x revisi gratis setelah hasil dikirimkan. Revisi mencakup perbaikan interpretasi dan output sesuai masukan dosen. Revisi tambahan di luar ketentuan dapat didiskusikan lebih lanjut.
Bagaimana skema pembayaran? +
Terdapat dua skema: (1) 2 tahap untuk BAB IV dan BAB IV–V — DP di awal, pelunasan setelah selesai. (2) 3 tahap untuk FULL BAB I–V dan Olahdata Only — DP di awal, Tahap 2 di tengah pengerjaan, pelunasan setelah selesai. Pembayaran via QRIS DANA atau QRIS GOPAY.
Kapan hasil dikirimkan ke saya? +
Hasil dikirimkan ke Google Drive kamu sesuai deadline yang disepakati saat registrasi. Kamu akan dihubungi via WhatsApp ketika hasil sudah siap untuk diunduh.
Apa itu sesi pendampingan? +
Sesi pendampingan adalah sesi tanya jawab via Google Meet atau Zoom setelah pelunasan. Di sesi ini kamu bisa bertanya tentang hasil pengerjaan, cara membaca output, dan persiapan sidang. Durasi sekitar 30–60 menit.
Bagaimana jika data saya masih kurang? +
Jika data yang diupload kurang lengkap atau ada masalah, tim AMKOBAR akan menghubungi kamu via WhatsApp untuk konfirmasi sebelum pengerjaan dimulai. Status project akan tetap di "Menunggu Review" sampai data lengkap.

Alur Layanan AMKOBAR

Proses dari pendaftaran hingga selesai

1
Registrasi & Deal Harga

Hubungi admin AMKOBAR untuk diskusi kebutuhan dan deal harga. Setelah deal, kamu akan mendapatkan link form registrasi.

2
Isi Form Registrasi

Isi form registrasi dengan data lengkap: nama, NIM/NPM, judul penelitian, pilihan aplikasi, dan jenis layanan.

3
Pembayaran DP

Lakukan pembayaran DP via QRIS DANA atau QRIS GOPAY. Konfirmasi pembayaran ke admin via WhatsApp.

4
Upload Data Penelitian

Upload file data (kuesioner, data mentah) ke Google Drive pribadi yang sudah disiapkan. Pastikan semua file lengkap.

5
Proses Pengerjaan

Tim AMKOBAR mulai mengerjakan sesuai layanan yang dipilih. Pantau status di tab "Cek Status" menggunakan NIM/NPM kamu.

6
Pelunasan

Setelah pengerjaan selesai, lakukan pelunasan sesuai skema pembayaran. Konfirmasi ke admin via WhatsApp.

7
Terima Hasil & Pendampingan

Hasil final dikirim ke Google Drive kamu. Dilanjutkan sesi pendampingan via Google Meet atau Zoom untuk penjelasan hasil.
